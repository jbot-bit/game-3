# Crown Court

[Download CrownCourt.exe for 64-bit Windows](https://github.com/jbot-bit/game-3/raw/refs/heads/main/CrownCourt.exe)

Download the one file and double-click it. No installer, ZIP extraction, engine or extra app is needed for practice and LAN. Use version **0.15.2** on every PC. The standard release is 64-bit Windows; the old 32-bit download is not updated for this release.

For a local match, one player chooses **Host** and the others **Join** using the address shown in the lobby. Choose **3 vs bots** for three friends against three bots, or **Custom teams** to choose sides and optional bot balancing.

Internet rooms are not enabled yet; a public relay still needs deployment. Friends in separate homes cannot connect through this release alone.
