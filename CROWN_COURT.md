# Crown Court

[Download CrownCourt.exe for 64-bit Windows](https://github.com/jbot-bit/game-3/raw/refs/heads/main/CrownCourt.exe)

Download the one file and double-click it. No installer, ZIP extraction, engine or extra app is needed for practice and LAN. Use version **0.17.0** on every PC. The standard release is 64-bit Windows; the old 32-bit download is not updated for this release.

For a local match, one player chooses **Host** and the others **Join** using the address shown in the lobby. Choose **3 vs bots** for three friends against three bots, or **Custom teams** to choose sides and optional bot balancing.

For tonight's temporary internet service, use [the Windows internet ZIP](https://github.com/jbot-bit/game-3/raw/refs/heads/main/CrownCourt-Internet-Windows.zip) or [the universal Mac ZIP](https://github.com/jbot-bit/game-3/raw/refs/heads/main/CrownCourt-macOS.zip). Read [the family instructions](CROWN_COURT_INTERNET.txt). The free relay depends on Dad's PC staying awake and online; a permanent server has not been purchased. The Windows internet ZIP contains this same 0.17.0 executable plus its endpoint configuration. Mac native launch still requires verification on the actual iMac.
