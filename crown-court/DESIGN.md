# Crown Court — 3D household first playable

The user confirmed Fall Guys Crown Jam as the reference and explicitly authorized immediate implementation. Build a separate original 3D game in Godot 4.7.2, keeping existing games untouched. The important experience is fluid running, jumping, grabbing, throwing, tackling and dunking across a roomy 40×72 court with raised routes and traveling boosts. Original bean-like characters and geometry; do not claim to be Epic's game.

One ball and two big hoops. Co-op has three human/bot crew versus three bots. Custom teams allow host-selected sides, two humans in 1v1, three humans in 2v1, and optional balancing bots (2v2). Free-for-all has three scoring players using the north hoop. Team rules follow observed full matches: five minutes or a four-point lead, one point per basket, three-second kickoff/reset with the clock stopped. Free-for-all keeps the original three-minute / first-seven rule. Ties continue until broken.

Controls follow inspected gameplay HUDs with PC/controller adaptations: WASD/stick movement, mouse/right-stick look, Space/A jump and double jump, left mouse/X catch or pass, right mouse/RT tackle or charge/release shoot, F/B airborne dunk, Ctrl/LB ball camera, Q/Y Hype. Dunking is a separate action. Catch has a short timing window; passes select a teammate in the aim direction. Shots show their actual ballistic path and overcharging makes them overshoot. A dunk has assisted ascent, a visible wind-up, and downward release that can be interrupted. Escape/F1 releases the mouse and opens pause/controls.

Ball movement uses deterministic 3D integration, substeps, gravity, banked floor/wall/backboard/rim collisions, and downward hoop-crossing scoring. The shared floor function drives both visible terrain and collision. Four pads enable high airborne routes. Giant, temporary launch pad, and homing blast powers consume earned Hype. Host owns scoring, physical state and possession; client inputs own only their seat. ENet UDP 28888 carries compressed snapshots, with bounded visual prediction on clients. Join by displayed LAN IPv4 address; practice runs offline.

Deliver Windows executable, portable ZIP, readable setup instructions and a visible launch. Verification must include rendered 3D game, actual keyboard input, physics behavior, multiplayer movement/grab/throw/scoring, disconnects and rematch. Clearly separate automated single-PC multi-process evidence from physical three-PC play and whether the game feels fun.

Wins earn free blind bags. Players start blank, unlock 11 outfits/accessories across four rarities, equip items with a 3D preview, and show their equipment to other players. Saves use an atomic replacement plus backup; match IDs prevent duplicate rewards. There are no purchases or stat-changing cosmetics.

The reference target is Crown Jam's gameplay. REFERENCE.md records actual full-match evidence and separates observations from local tuning; no proprietary physics values or assets were extracted. Exact feel and physical household performance remain human playtest questions. The user subsequently expanded the scope to controller menus and internet play for friends in separate homes. Version 0.4 supports private Tailscale connectivity using the existing host-authoritative ENet protocol, displayed overlay addresses and hostnames. Public matchmaking/relay hosting is outside this local release. Tailscale sign-in and trusted-friend membership or device sharing are separate setup steps. Simulated latency/loss checks do not establish real internet play.
